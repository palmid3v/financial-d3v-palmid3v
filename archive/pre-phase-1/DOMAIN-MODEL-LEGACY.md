# Pre-Phase-1 Legacy Domain Model

This document preserves the previous domain model for historical traceability only.

It is not part of the active Go package tree and must not be used as the current domain design.

Legacy types included:
- User
- Organization
- Account / AccountType
- Transaction / TransactionType
- TransactionCategory
- Budget / BudgetItem
- SavingsGoal
- Debt / DebtPayment
- Asset
- Liability
- Employee / Contract
- PayrollPeriod / PayrollRun
- Earning / Deduction
- AuditEvent

The active domain was intentionally rebuilt in FASE 2 from the personal-finance product specification.
