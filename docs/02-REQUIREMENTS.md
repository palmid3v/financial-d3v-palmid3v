# Requirements

## Functional foundation

- Manage accounts.
- Record financial transactions.
- Categorize transactions.
- Define budgets.
- Track savings goals.
- Track debts and payments.
- Track assets and liabilities.
- Calculate net worth.
- Represent payroll entities.
- Produce financial reports.
- Audit sensitive mutations.

## Non-functional

- Go-first backend.
- PostgreSQL persistence.
- Deterministic monetary representation.
- Server-side authorization.
- Testable domain behavior.
- Responsive desktop and mobile UX.
- Dark Mode as the primary visual theme.

## Explicit exclusions for the foundation

- No invented Colombian payroll/tax rules.
- No premature implementation of every domain.
- No frontend business-rule duplication.
