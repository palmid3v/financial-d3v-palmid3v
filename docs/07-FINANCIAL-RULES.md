# Financial Rules — New Baseline

**Status: FASE 2 PENDING**

The authoritative financial rules will be rebuilt from the new product definition.

FASE 2 must define and test:
- money representation;
- account balance semantics;
- transaction effects;
- transfer conservation;
- budget inclusion rules;
- savings progress;
- financial-period boundaries.

Every derived metric must have an explicit formula.

Educational output must distinguish fact, calculation, interpretation and action.

Legal, tax and regulatory rules must never be invented. Authoritative external rules must be sourced and dated before being used.
