# Testing Strategy

## Levels

1. Unit/domain.
2. Application service.
3. Repository integration.
4. HTTP/API.
5. End-to-end for critical flows.

## Financial regression cases

- transfer conservation;
- balance reproducibility;
- budget date boundaries;
- savings progress;
- debt balance;
- net worth;
- payroll reproducibility.

The same inputs plus the same rule-set version must produce the same expected payroll result.
