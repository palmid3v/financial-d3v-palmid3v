# Learning Go Through Financial-D3v

Financial-D3v is the real application.

The separate Go learning lab remains the experimentation space.

## Learning loop

Learn concept → practice in GOLang-learning → design an application use case → implement in Financial-D3v → test → document → review.

## Go concepts

- HTTP servers
- Routing
- JSON
- Interfaces
- Dependency injection
- Context
- Error handling
- Testing
- Concurrency where genuinely useful
- Firestore repository integration
- Configuration
- Logging
- Authentication/authorization integration
- API design

## Financial learning loop

The same feature should also teach a financial concept.

Example:

Build budget feature → understand budget mechanics → implement rules → use the feature personally → review real spending → learn.

The project is therefore both a software laboratory and a practical financial education tool.

Do not merge experimental learning code into the production application without a deliberate design decision.
