# Financial-D3v Frontend

Phase 13 mobile-first React/Vite/Tailwind/PWA product shell.

## Run

```bash
npm install
npm run dev
```

Set `VITE_API_BASE_URL` when the API is not running on `http://localhost:8080`.

The current shell uses `X-Owner-ID` only for local development when API authentication is not required. Production authentication must use Firebase ID tokens.
